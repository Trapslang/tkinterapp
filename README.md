# Multi-Tool Tkinter Application

A Python desktop application built with Tkinter featuring multiple interactive tools and mini-projects inside one GUI.

## Features

### LOGIN PAGE
*login before accessing the pages.
*sign up if you don't have anaccount
### Settings Page
* Dark mode
* Light mode
* Dynamic theme switching

### Geography Quiz

* Multiple choice questions
* Image-based question
* Score system
* Colored answer feedback
* Popup messages based on results

### Drawing Canvas

* Free drawing mode
* Straight line tool
* Rectangle tool
* Circle tool
* Text tool
* Multiple colors
* Adjustable brush thickness
* Clear canvas button

### Graph Generator

* Creates a bar chart using custom values
* Visualizes scores for multiple people

### Memory Game

* 4x4 memory card game
* Randomized cards every round
* Match detection system
* Victory popup when completed

### Math Tools

#### Pythagorean Calculator

Calculates the hypotenuse using:

a² + b² = c²

#### Circle Calculator

Calculates:

* Area
* Circumference

Includes:

* Calculation history
* Scrollable history list
* Clear history button

# Installation

## 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
```

## 2. Open the folder

```bash
cd YOUR_REPOSITORY
```

## 3. Run the application

```bash
python main.py
```
